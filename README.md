# Koya Content Studio

An AI-assisted content research, editorial review, and publishing-preparation application for a marketing/content team. Built for the Koya AI Automation Academy Week 4 project.

See `../SYSTEM-DESIGN-NEXTJS.md` and `../IMPLEMENTATION-PLAN-NEXTJS.md` in the parent folder for the full system design and build plan. This README will be completed with setup, roles, environment variables, and testing instructions as implementation proceeds (Task 22).

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm check     # lint + typecheck + unit/integration tests
pnpm test:e2e  # Playwright end-to-end tests
pnpm build     # production build
```
